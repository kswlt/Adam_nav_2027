## 查看与启动

当前实例保持运行，直接连接 Foxglove：`ws://192.168.1.164:8765`，3D Display frame 选择 `odom`。
可导入仓库 `src/rm_nav_bringup/config/foxglove/mapping_low_latency.json`。
开启 `/visualization/live_map_preview`、`/visualization/lio_path`、`/visualization/chassis_path`、TF；
原始点云选择 `/livox/lidar`。默认预览 1 Hz、最多 5 万点，原始云约 10 Hz。
不要同时打开多路完整累积云，否则可能再次产生网络/渲染积压。

重启电脑后在不同终端按顺序执行以下实际部署脚本；已有实例运行时不要再启动一套：

```bash
cd /home/asus/nav_2027_vehicle_config_164
bash start_driver_20261020.bash
# 第二终端
bash start_state_20261020.bash
# 第三终端
bash start_foxglove_20261020.bash
# 第四终端（需要保存关键帧时）
bash start_mapping_20261020.bash
```

各终端 Ctrl+C 停止对应新进程。脚本和环境快照已收录于 `tools/deployment/20261020`，不包含 SSH 凭据。
首次部署的后台实例请按实际 PID/PGID 单独停止，禁止 `pkill ros2` 或停止原车所有导航进程。
