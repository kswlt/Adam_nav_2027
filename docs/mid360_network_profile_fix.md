# MID-360 插线网络修复（2026-10-10）

现场确认 `enp86s0` 有物理链路，但 NetworkManager 自动选择 DHCP 的“配置 1”
（fccef4d9-a0b9-4f1e-bb4f-19df898309cd），停留在获取 IP 阶段。
雷达专用“有线连接 1”（117cff0b-31b9-3377-ba9e-a6204d7d1c10）
虽然已设成 /32，自动连接优先级仍为 -999，未被选择。

修复：停用“配置 1”的自动连接；将雷达专用配置绑定 enp86s0，优先级设为 100，
清空 gateway，保持 192.168.1.50/32、never-default 和 192.168.1.3/32 专用路由。
激活雷达专用连接后验证：

- 到开发主机 192.168.1.134 的路由：wlo1，源 192.168.1.145。
- 到雷达 192.168.1.3 的路由：enp86s0，源 192.168.1.50。
- 雷达 ping：3/3 成功，平均 1.539 ms；SSH 保持可用。

这些结果证明当前网络连通性；尚未验证雷达驱动负载下的长时间 SSH 稳定性，
也未再次重启或拔插验证持久化行为。未修改 Wi-Fi、串口协议或控制输出。
